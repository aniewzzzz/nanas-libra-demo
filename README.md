# Nana’s library

[Open the interactive demo](https://aniewzzzz.github.io/nanas-libra-demo/)

A floating gallery of illustrated cards arranged into a 3D heart. Drag to explore, click a card to see the artwork, or press **Surprise ♡** to gather the cards and launch fireworks.

The demo uses original vector illustrations generated in the page. `index.html` is self-contained and can also be opened offline.
